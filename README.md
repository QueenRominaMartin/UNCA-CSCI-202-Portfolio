***Project Format*** <br>
`ProjectName.java` - The actual class with the source code of the project <br>
`ProjectNameTester.java` - The file with the Main method to test the source code

**Rational Number Project** <br>
This project is used to represent any and all rational and real numbers in Java to avoid dealing with floating point math and other rounding inconsistencies that occur when using doubles or floats.

**Complex Number Project** <br>
This project is used to represent complex numbers that involve the imaginary number i in Java.

**Sum Project** <br>
A very small project that implements several methods that calculate the sum of all numbers from 1 to the given number passed through as an argument.
